About this project

This local teaching project connects three HTML pages with responsive CSS, typed data, search, filters and optional bookmarks. The six records are sample metadata, not six additional courses.

Your checks

  • Search and topic filters combine.
  • An empty search result offers recovery.
  • Unknown course identifiers show a helpful message.
  • Bookmarks survive a reload when local storage is available.
  • Blocked storage does not block course access.
  • All controls work by keyboard and at narrow widths.

No account, remote API or personal learning data is used. Text is inserted as text, not as HTML.
